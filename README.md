# Optimizer

Sistema de alocação de salas baseado em Pesquisa Operacional (PLI).

## Stack

- Backend: Django + DRF + PuLP + NumPy
- Frontend: React + Vite + TypeScript

## Estrutura

- backend/
- frontend/
- docs/

## Setup

### Backend
cd backend
pip install -r requirements.txt
python manage.py runserver

### Frontend
cd frontend
npm install
npm run dev
